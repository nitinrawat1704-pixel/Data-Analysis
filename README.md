## Data Pipeline

1. Raw CSV datasets were loaded and cleaned using Python/Pandas.
2. Missing values, duplicates, invalid transactions, and date formats were handled.
3. The cleaned datasets were exported as CSV files.
4. The cleaned CSV files were imported into MySQL Workbench.
5. SQL was used for business analysis, including transaction, customer, merchant, and offer analysis.
6. The analyzed data will be used to build an interactive Power BI dashboard.
